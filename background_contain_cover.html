Begineer Guide: Understand contain vs cover

Section 1: background-size: contain

Contain: Isme image poori tarah se box ke andar fit ho jaati hai (poori image dikhti hai, bina cut hone ke). Agar box ka size aur image ka ratio alag hai, toh aas-paas khali jagah (space) reh sakti hai.

Section 2: background-size: cover

Cover: Isme image pooray box ko ache se cover (fill) kar leti hai. Box mai koi khali jagah nahi rehti, par agar image ka size alag ho toh thodi image crop (kat) sakti hai.
